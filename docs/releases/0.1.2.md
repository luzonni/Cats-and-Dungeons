# Release 0.1.2-alpha

## Novidades

### Overlay de depuração

| Tecla | Mostra |
|---|---|
| `F3` | Informações do jogo (FPS, ticks, hardware) |
| `F4` | Hitbox das entidades |
| `F5` | Grade de tiles |
| `F6` | Bounds das partículas |

### Zoom de câmera

- `Ctrl` + `=` — aproxima
- `Ctrl` + `-` — afasta

## Execução

Exige **Java 21 ou superior**.

```sh
./jvm-21/bin/java -jar ./Modules.jar
```

> A partir da 0.1.3 o projeto usa Gradle. Veja o README para as instruções atuais.
